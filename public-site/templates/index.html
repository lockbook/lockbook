Encryption

We built a notebook we can’t read.

Your keys are generated on your device and never leave it. Everything is encrypted before it syncs, so what reaches our servers is noise. Sharing hands a key to a person you name — never to us.

Open formats

Files you could still read if we disappeared.

There is no proprietary container and no database you need our app to open. Folders are folders, notes are Markdown, drawings are SVG. Export writes exactly what you see here to disk — and every one of these opens in software that has nothing to do with us.

A directory tree. Your notes are files in folders, named by you. Export writes them to disk in this shape — no manifest, no index, nothing to reconstruct.

CommonMark. Tables, task lists, footnotes and Obsidian-style [[wikilinks]]. The same file renders on GitHub, converts with pandoc, and opens in every editor you already have.

SVG. Every stroke is a path in an open vector format. Drop the file into Inkscape, Illustrator, Figma or a browser and it opens — because it is not a picture of a drawing, it is the drawing.

Platforms

Five native apps, one core.

The hard parts — encryption, sync, conflict resolution — live in a single Rust library that every client shares. The interface on top is written for its own platform, so each app launches instantly and behaves the way that platform should. No Electron, no web view.
