Open formats

Files you could still read if we disappeared.

Notes are Markdown.

CommonMark with tables, task lists, footnotes and Obsidian-style [[wikilinks]]. The file you write here is the file on disk — it renders on GitHub, converts with pandoc, and opens in every editor you already have.

Also opens in GitHub, Obsidian, VS Code, pandoc.

Drawings are SVG.

Every stroke is a path in an open vector format. It is not a picture of a drawing, it is the drawing — drop the file into Inkscape, Illustrator, Figma or a browser and it opens.

Also opens in Inkscape, Illustrator, Figma, any browser.

Folders are folders.

Export writes your notebook to disk exactly like this — folders you named, Markdown and SVG inside. No manifest, no database, nothing to reconstruct.

Back it up with anything: rsync, git, a USB stick.

Encryption

We built a notebook we can’t read.

Your keys are generated on your device and never leave it. Everything is encrypted before it syncs, so what reaches our servers is noise. Your notes live on your device first, so offline isn’t a mode — it’s the default. Sharing hands a key to a person you name — never to us.
